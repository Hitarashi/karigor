# Karigor Context

## Overview

`karigor` is a framework-agnostic, developer-friendly CLI application builder and terminal UI toolkit for Rust.
It provides a declarative command kernel, argument parsing, interactive prompts, formatted tables, progress spinners,
and template generation capabilities.
